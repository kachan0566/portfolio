# ① 転職の成功条件を決める

## 状態：✅ 完了

### 目的

求人を見るときに、

**応募する / 保留 / 見送る**

を自分で判断できる基準を持つ。

---

## 1. 仕事内容

### 最優先

理想は、

- 社内SE・情報システム系
- 社内の困りごとや業務課題を理解する
- システムの改善・改修・開発に関われる
- 将来的には、自分から改善案を出せる
- 改善案を実装まで持っていける

### 次点

- 自社開発エンジニア
- 業務システム開発
- バックエンド寄りの開発
- 保守だけでなく改善・機能追加にも関われる仕事

### 避けたい仕事

- 営業中心
- 顧客折衝中心
- クレーム対応中心
- 現時点でのコンサル中心
- 手動テスト専任
- システム監視だけを続ける仕事
- コードを書き続けるだけで業務改善に関われない仕事

## 7. 教育・レビュー体制



### 必須

- 経験者によるコードレビューがある
- 質問できる先輩・メンターがいる
- 未経験者に段階的に仕事を任せる
- いきなり難しい仕事を丸投げされない



### できれば

- 定期1on1
- 入社時研修
- 社内ドキュメント
- 開発環境構築などの手順書
- 実装前後に相談・フィードバックできる



### あれば嬉しい

- 資格補助
- 書籍購入補助
- Udemyなどの学習支援
- 社内勉強会
