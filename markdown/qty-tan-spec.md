# 反数管理 仕様書

生機・製品の数量を **反数をメイン表示** とし、**メートルを正（ソース・オブ・トゥルース）** として管理する。

---

## Phase 1（実装済み／在庫フェーズ）

### 基本ルール

| 項目 | 内容 |
|------|------|
| 正とする数量 | **メートル（m）** |
| 反数 | メートル ÷ 換算率（小数2桁） |
| 保存 | `qty_meters`（正）＋ `qty_tan_calc`（計算値）＋ `qty_tan_input`（入力記録・任意） |
| 表示 | **「2.40反 / 120m」** を同格表示 |
| 換算率 | 生機・製品は別々（例：生機 100m/反、製品 50m/反） |
| 価格・コスト | 円/m のまま |
| レシピ | kg/m のまま |
| 品番マスタの単位欄 | m のまま |
| 安全在庫 | メートルが正 → `stock_min_tan` は自動計算 |

### 生機在庫（染工場仕掛）

| 項目 | 内容 |
|------|------|
| 場所 | 染工場の仕掛在庫（染色待ち） |
| キー | 生機品番 ＋ 発注ロット（PO） |
| 増えるタイミング | 発注工程 **「生機出荷済」**（自動） |
| 減るタイミング | 発注工程 **「染機投入済」** → 製品在庫へ移動 |
| 移動ルール | 生機1反 → 製品2反（100m はそのまま、反数のみ換算） |
| 画面 | 在庫一覧 **生機タブ** ＋ **発注詳細** |

### 実装ファイル（Phase 1）

- `app/Support/QtyHelper.php` … 表示・換算
- `app/Support/GreigeInventory.php` … 生機在庫の算出・工程連動
- `app/Support/DemoState.php` … 工程オーバーレイ・染色移動
- `resources/views/inventory/index.blade.php` … 製品／生機タブ
- `resources/views/purchases/show.blade.php` … 発注詳細・生機在庫

---

## Phase 2（実装済み・受注・引当・出荷）

- 受注登録・編集、引当パネル、出荷登録で **反数を基本入力**
- 画面ごとに **反数 / メートル切替**（`localStorage` で前回の選択を記憶）
- 反数入力時に **換算メートルをリアルタイム表示**
- 内部保存は **メートルが正**（hidden input で送信）
- 入荷による引当変換履歴も **「1.8反 / 90m」** 形式

## 将来拡張

### 染工場・織工場システム連携

| 現状（Phase 1） | 将来 |
|-----------------|------|
| 工程「生機出荷済」で生機在庫増 | 染工場の入荷処理完了時に API で自動反映 |
| 品番ごとの標準 m/反 | **反ごとの実測 m** を工場から受信 |
| ロット（PO）単位の集計在庫 | **反明細**（1物理反 = 1レコード） |

### 反明細のデータイメージ（将来）

```
tan_id:        KB-A-PO003-001
greige_sku:    KB-A
po_id:         3
qty_meters:    98.2        ← 正（織工場 or 染工場が計量）
qty_tan_calc:  0.98        ← 標準換算（表示用）
location:      dye_factory
measured_at:   2026-06-16
source:        weaving_factory | dye_factory
status:        greige_wip | dyeing | product_stock
```

### 反ごとの長さのばらつき

テキスタイルでは **1反ごとに長さが異なる** のが通常。

- **標準 m/反** … 見積・反数入力の目安（Phase 1）
- **実測 m** … 連携後は各反の正（Phase 3 以降）
- **1物理反 = 1反** … 連携後は端数反より反ID単位の管理が主

### 段階的な移行

1. **Phase 1** … 標準換算率 ＋ ロット集計 ＋ 工程連動（現在）
2. **Phase 2** … 取引画面の反数入力
3. **Phase 3** … 反明細テーブル追加、工場 API 連携、実測 m を正とするオプション

Phase 1 の `GreigeInventory`（PO × 生機品番）は、将来 **反リストが PO にぶら下がる** 形に拡張する。

### その他の将来検討

- 染色ロス（投入 m と製品 m の差）
- 生機の直接販売（現状は対象外）
- 場所別在庫（自社 / 染工場 / 織工場）
