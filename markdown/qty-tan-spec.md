# 反数管理 仕様書

生機・製品の数量は **反数をメイン表示** とし、業務ごとに「正とする数量」の持ち方を分ける。

> **発注工程との関係** … 工程表示は `PurchaseOrderDisplay`（種別ごと）が正。詳細は `markdown/change-instructions.md` **付録B** と `memo/DB.md` を参照。
> 旧「8段階進捗で在庫を動かす」連動（`GreigeInventory::handleStageTransition`）は **廃止済み**。

---

## 数量の基本ルール

| 項目 | 内容 |
| --- | --- |
| 画面表示 | **「2.5反 / 125m」** 形式（反がメイン、m がサブ） |
| 換算率 | 生機・製品は品番ごと（例：生機 100m/反、製品 50m/反） |
| 反数を扱う工程 | 受注・発注・入荷・引当・出荷のすべてを **0.25反刻み** に統一する |
| 許可する反数 | `0.25`、`0.5`、`0.75`、`1`、`1.25` など、0.25の倍数 |
| 許可しない反数 | `0.1`、`0.3`、`1.1` など、0.25の倍数ではない値 |
| 不正な反数 | 最も近い値へ自動で丸めず、保存せずに入力エラーを表示する |
| m指定受注 | 反数入力の例外として維持し、入力されたm数を正とする |
| m数の精度 | 換算m・実測mとも小数2桁まで保持する。例：製品50m/反の0.25反は12.50m |
| 入荷（在庫化） | 0.25反刻み ＋ 反ごとの実測m |
| 価格・コスト | 円/m のまま |
| レシピ | kg/m のまま |

### 何を「正」として保存するか

| 領域 | 正とする値 | 補足 |
| --- | --- | --- |
| 反数指定の受注・発注・引当・出荷 | **0.25反刻みの反数** | mは品番の標準m/反から小数2桁で換算する |
| m指定受注 | **入力されたm数** | 反数指定の例外。見込反数は表示・在庫確認用に換算する |
| 入荷反明細 | **反ごとの実測 m**（`actual_qty_m`） | 標準 m/反 は見積用 |
| 在庫集計 | 反明細の合計（`GreigeRoll` / `ProductRoll`） | ロット集計は明細の足し算 |

### m指定受注の境界

- m指定受注は、0.25反刻みへの自動丸めを行わない。
- 出荷時は実測mと利用可能な在庫反を使い、必要な反を選択する。
- 「反数は0.25刻み」という制約は、m指定受注の入力m数そのものには適用しない。
- m指定受注から表示用の見込反数を算出しても、その見込反数で入力m数を上書きしない。

### 出荷時の反分割

- 1反の在庫から0.25反を出荷した場合は、0.25反だけを消費し、残り0.75反を同じ在庫反に残す。
- 分割して出荷する反は、標準m/反による自動換算ではなく、出荷時に実際の出荷m数を入力する。
- 丸ごと出荷する反は、入荷時に記録した実測mをそのまま出荷mとして使う。
- 複数反を同時に出荷するときは、FIFOで丸ごと消費する反の実測mを自動集計し、最後に分割する反だけ出荷実測mを入力する。
- 分割元の在庫反には、出荷した反数と実測mを差し引いた残反数・残mを保持する。
- 出荷実測mは0より大きく、分割元の残mを超えてはならない。

### 既存データの移行方針

- 0.25反刻みでない既存値は、移行前に一覧化する。
- 不正値を自動で丸めたり、黙って切り捨てたりしない。
- 元伝票・実測値を確認し、1件ずつ妥当な値へ修正する。
- 不正値が残った状態で新しい制約を有効にしない。

### 実装上の必須条件

- 画面の入力刻み、サーバー側の検証、計算処理、DBの型、シード、テストを同じ0.25反仕様にそろえる。
- 入力値の検証は丸め処理より先に行い、`0.3`を`0.25`として受け付けない。
- `qty_tan`を整数へ変換する処理を残さない。
- 0.25反×50m＝12.50mを正確に扱えるよう、反数に対応するm列・計算・表示は小数2桁を保持する。
- kg、単価、原価など反数ではない数量には、0.25反刻みを適用しない。

## 生機在庫（染工場仕掛）

| 項目 | 内容 |
| --- | --- |
| 場所 | 染工場の仕掛在庫（染色待ち） |
| キー | 生機品番 ＋ **生機発注**（PO） |
| データ源 | `GreigeRoll`（反明細）があればそれを優先。なければ発注の入荷済み数量 |
| 増えるタイミング | **生機発注への入荷処理**（織り上がり登録） |
| 減るタイミング（在庫から外れる） | **製品発注を染機投入済にしたとき**（`GreigeDyeInput` → `in_dyeing`） |
| 減るタイミング（消費） | **染色完了登録**（`TanRollRecorder::recordDyeingCompletion`）で `consumed` |
| 画面 | 在庫一覧 **生機タブ** ＋ 発注詳細 |

### 発注工程との対応（表示のみ）

生機在庫の増減は **工程バッジの変更では動かない**。

| 画面の工程表示 | 在庫との関係 |
| --- | --- |
| 生機出荷済（染工場入荷開始） | 入荷済みならこのラベルになるが、在庫は **入荷記録** で増える |
| 染機投入済（製品発注の手動工程） | 生機反を `in_dyeing` に移動（`GreigeDyeInput`）。生機在庫カウントから外れる |
| 染色完了登録 | `in_dyeing` の反を `consumed` にし、製品反を生成 |

## 製品在庫・染色移動

| 項目 | 内容 |
| --- | --- |
| データ源 | `ProductRoll`（反明細） |
| 増えるタイミング | 製品発注への入荷、または染色完了で生機から生成 |
| 移動ルール | 生機反を消費し、製品反を作成（m は実測を引き継ぐ。反数は品番換算） |
| デモ補助 | `DemoState::applyDyeTransfer` … 旧デモ用の m 移動記録（工程とは独立） |
