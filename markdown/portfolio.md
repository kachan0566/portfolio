7# 受発注・在庫・売上管理システム(東レでの業務をイメージ)

## アプリ概要

前職の繊維メーカーにおいて、

- 受発注状況が分かりにくい
- 現在庫が見にくい
- 月ごとの糸価格変動によって製造コストや粗利が把握しづらい

という課題があった。

本システムでは、糸・生機・製品という繊維生産の流れに沿って受発注・入出荷・在庫を一元管理し、  
月別の糸単価と2段階レシピ（生機レシピ＋製品レシピ）から製造コスト（円/m）を自動計算することで、  
月ごとの粗利を可視化できるようにする。

また、受注に対する在庫引当・発注引当のほか、未出荷受注・未入荷発注・在庫不足などを  
ダッシュボードで確認できるようにし、業務状況を把握しやすくする。

# 業務フロー

```text
【マスタ登録】
得意先・仕入先（種別：紡績／織編／染工）登録
↓
生機品番・製品品番（カラー別）登録
↓
生機レシピ登録（糸の使用量・ロス率・織賃）
↓
製品レシピ登録（染色加工料）
↓
月別糸価格登録

【取引フロー】
受注登録（品番・反数・納期・出荷予定日）
↓
引当（現在庫引当 / 発注引当）
↓
発注登録（糸発注 / 生機発注 / 製品発注）
↓
入荷処理（種別ごと。製品・生機は反明細、糸は kg）
↓
出荷処理（引当済み数量のみ。分納可）
↓
売上・製造コスト・粗利を自動集計
```

### 在庫確認フロー（受注対応）

```text
受注一覧で品番を確認
↓
品番をクリック → 在庫詳細画面へ遷移
↓
現在庫・受注残・過不足を確認（横棒グラフで比較）
↓
不足の場合は発注登録 → 入荷処理 → 引当
↓
出荷処理で受注を消化
```

# 設計方針：受注・発注（約束）と入荷・出荷（実績）を分ける

本システムでは「受注・発注」と「入荷・出荷」を別画面として管理する。  
これは、**1件の注文に対して、実際のモノの出入りは複数回発生する**ためである。

| 区分 | 画面 | 役割 | たとえ |
| --- | --- | --- | --- |
| 約束（計画） | 受注管理 | 得意先と「いつまでに・何を・いくつ納めるか」を約束する | 注文書 |
| 約束（計画） | 発注管理 | 糸・生機・製品の3種類の発注と、種別ごとの生産工程を追跡する | 発注書 |
| 実績（記録） | 出荷処理 | 実際に送ったモノを1件ずつ記録する（受注と紐付け） | 発送伝票 |
| 実績（記録） | 入荷処理 | 実際に届いたモノを1件ずつ記録する（発注と紐付け） | 受領書 |

例：受注200個に対し、80個を先に出荷し、残り120個を後日出荷する（分納）。  
このとき「受注は1件」「出荷は2件」となり、両者を別データで持つ必要がある。

```text
受注（1件） ── 出荷（複数件・分納可）
発注（1件） ── 入荷（複数件・分納可）
```

- 受注・発注は **「約束」** なので、数量・納期・進捗を1件として管理する。
- 入荷・出荷は **「実績」** なので、実際に動いた日付・数量を都度記録し、在庫を増減させる。
- 出荷処理の「受注元」、入荷処理の「発注番号」から、元の受注・発注へ画面遷移できるようにし、約束と実績のつながりをたどれるようにしている。

# 外部工場連携（将来方針）

織編・染工などは **業務上の外部取引先**（仕入先マスタ）として扱う。  
**IT の外部連携**（工場のシステムが自社システムにデータを送る）は、現時点では未実装とする。

## フェーズ1（現状）

- 入荷・出荷の実績は **自社担当者が Blade 画面から登録** する。
- 工場からの連絡（電話・メール等）を人がシステムに反映する想定。
- 画面は Laravel 標準の Web アプリ（フォーム送信 → リダイレクト）のまま完成させる。

## フェーズ2（将来）

- 織編・染工などの **工場システムから入荷実績**（数量・反明細・実測 m 等）を受信し、**在庫を自動反映** する。
- 連携方式は REST API（JSON）を第一候補とする。工場側の事情により CSV 取込から始める場合もある。
- **社内の手入力画面は併存可能** とする（API に全面移行しない）。

## 実装の原則

- 入荷登録の本体処理は `ReceivingRegistrar`、出荷登録は `ShipmentRegistrar` に集約する。
- 将来の工場向け API は、これら Registrar を **画面と同じ入口から呼ぶ**（ロジックの二重実装をしない）。
- 工場向け JSON API の仕様書は OpenAPI または `memo/API/` 形式で **連携部分だけ** 書く（社内画面用仕様とは分ける）。
