## 1. 目的・スコープ

### 1.1 背景（解決したい課題）

前職の繊維メーカーにおいて、次の課題があった。

- 受発注状況が分かりにくい
- 現在庫が見にくい
- 月ごとの糸価格変動によって製造コストや粗利が把握しづらい



### 1.2 システムの目的

糸・生機・製品という繊維生産の流れに沿って、受発注・入出荷・在庫を一元管理する。  
月別の糸単価と2段階レシピ（生機レシピ＋製品レシピ）から製造コスト（円/m）を自動計算し、出荷実績をもとに売上・粗利を可視化する。

### 1.3 スコープ（含むもの）

- マスタ管理（得意先・仕入先・商品・レシピ・月別糸価格）
- 取引管理（受注・発注・入荷・出荷・引当）
- 在庫管理（製品・生機・糸、月末予想、長期在庫）
- 売上・粗利の集計（実績・見通し）
- ダッシュボードによる業務状況の可視化



### 1.4 スコープ外（現時点）

- ログイン・認証（将来検討）
- 工場システムとの IT 連携（将来方針として設計のみ。詳細は `memo/integration/`）
- 売上一覧・在庫一覧・受発注一覧 CSV（ボタンはあるが未実装）

## 3. 業務フロー



### 3.1 マスタ登録〜取引の流れ

```text
【マスタ登録】
得意先・仕入先（種別：紡績／織編／染工）登録
↓
生機品番・製品品番（カラー別）登録
↓
生機レシピ登録（糸の使用量・ロス率・織賃）
↓
製品レシピ登録（染色加工料）
↓
月別糸価格登録

【取引フロー】
受注登録（品番・反数・納期・出荷予定日）
↓
引当（現在庫引当 / 発注引当）
↓
発注登録（糸発注 / 生機発注 / 製品発注）
↓
入荷処理（種別ごと。製品・生機は反明細、糸は kg）
↓
出荷処理（引当済み数量のみ。分納可）
↓
売上・製造コスト・粗利を自動集計
```



### 3.2 在庫確認フロー（受注対応）

```text
受注一覧で品番を確認
↓
品番をクリック → 在庫詳細画面へ遷移
↓
現在庫・受注残・過不足を確認
↓
不足の場合は発注登録 → 入荷処理 → 引当
↓
出荷処理で受注を消化
```



### 3.3 約束と実績の関係

1件の受注・発注に対し、入荷・出荷は複数回発生しうる（分納・分割入荷）。

```text
受注（1件） ── 出荷（複数件・分納可）
発注（1件） ── 入荷（複数件・分納可）
```

- 受注・発注は数量・納期・進捗を1件として管理する
- 入荷・出荷は実際の日付・数量を都度記録し、在庫を増減させる
- 実績から元の受注・発注へたどれること

## 5. 横断ルール



### 5.1 表示方針

- 全画面で品番（SKU）を基準に表示する（カラーは補助表示）
- 数量は「反数（メイン）/ メートル（サブ）」形式で統一する
- 価格・コストは円/m で表示する

詳細 … `[qty-tan-spec.md](qty-tan-spec.md)`

### 5.2 受注引当

- **現在庫引当**：入荷済み在庫を受注に割り当てる
- **発注引当**：未入荷の発注残を受注に紐付ける
- 入荷時に発注引当 → 現在庫引当へ変換する
- **出荷は現在庫引当済みの数量のみ可能**（発注引当のみの数量は入荷後に出荷可能）



### 5.3 発注種別


| 種別   | 依頼先の例  | 用途       |
| ---- | ------ | -------- |
| 糸発注  | 紡績メーカー | 糸の調達     |
| 生機発注 | 織編工場   | 生機の製造依頼  |
| 製品発注 | 染工場    | 染色・加工の依頼 |


仕入先の種別により、発注種別ごとに選択できる依頼先が制限される。

### 5.4 在庫の種類


| 種類   | 管理単位                     | 増減のタイミング（概要）      |
| ---- | ------------------------ | ----------------- |
| 製品在庫 | 反明細（product_rolls）       | 製品入荷で増、出荷で減       |
| 生機在庫 | 反明細（greige_rolls）        | 生機入荷で増、染工投入等で減    |
| 糸在庫  | kg（yarn_stock_movements） | 糸入荷で増、生機発注への引当等で減 |


詳細 … `[qty-tan-spec.md](qty-tan-spec.md)`、`[memo/DB.md](../memo/DB.md)`

## 6. 計算ルール



### 6.1 製造コスト単価（円/m）

```text
生機単価 = Σ（糸単価 × 使用量 × (1 + ロス率)）+ 織賃
製造コスト単価 = 生機単価 + 染色加工料
```

- 糸単価は月別糸価格（`material_prices`）から取得する
- レシピまたは糸単価が未登録の場合、原価は算出不可とする



### 6.2 売上・粗利（出荷実績ベース）

```text
売上 = 出荷メートル数 × 販売単価（円/m）
製造コスト = 出荷メートル数 × 製造コスト単価（円/m）
粗利 = 売上 − 製造コスト
```

- 原価算出不可の品番は粗利合算から除外する



### 6.3 在庫金額

```text
在庫金額 = 製造コスト単価（円/m）× 現在庫（m）
```

- 原価算出不可の品番は合算から除外する

## 7. 機能要件（領域別サマリー）

画面の列・ボタンなどの詳細は書かない。振る舞いの要点のみ。

### 7.1 マスタ

- **得意先**：受注先の企業を管理する
- **仕入先**：発注先を種別（紡績 / 織編 / 染工）付きで管理する
- **商品**：生機品番（親）と製品品番（子・カラー別）を管理する
- **糸**：マスタは DB / シーダーで保持。専用の一覧・登録画面は未実装
- **月別糸価格**：糸ごとの年月別単価を管理する
- **レシピ**：生機レシピ（糸・ロス率・織賃）と製品レシピ（染色加工料）を管理する



### 7.2 受注

- 得意先・品番・数量（反数ベース。メートル指定にも対応）・納期・出荷予定日を登録する
- 出荷ステータス（未出荷 / 一部出荷 / 出荷済み）を管理する
- 引当の登録・解除、発注との紐付けができる
- 出荷計画の作成ができる（任意）



### 7.3 発注

- 糸・生機・製品の3種類の発注を登録・一覧できる
- 依頼先・出荷先・納期・入荷予定日・工程を管理する
- 入荷ステータス（下書き / 発注済 / 一部入荷 / 入荷完了 / キャンセル）を管理する
- 糸在庫不足の発注には警告を表示する
- 製品発注は受注と紐付けできる



### 7.4 入荷・出荷

- **入荷**：発注種別ごとに入荷登録。複数明細行の一括入荷に対応。生機・製品は反明細、糸は kg
- **出荷**：受注に対する出荷登録（分納可）。引当済み数量のみ出荷確定可能



### 7.5 在庫・売上

- **在庫**：製品・生機・糸の在庫確認、品番別の過不足、月末予想、長期在庫
- **売上・粗利**：品番別の実績集計と見通し。対象月の切り替えが可能
- **ダッシュボード**：KPI・グラフ・アラート・最近の受注を表示する



### 7.6 CSV


| 種別                       | 状態          |
| ------------------------ | ----------- |
| 売上一覧・在庫一覧・受発注一覧 CSV      | 未実装（ボタンは無効） |
| 製品・生機の月末予想 CSV、売上見通し CSV | 実装済         |
