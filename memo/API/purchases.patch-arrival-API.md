# 入荷予定日・メモ　更新API

## 概要
- 発注一覧の入荷予定日とメモ欄の保存ボタンを押した時に内容を更新する

## エンドポイント
- URL: /purchases/{purchase}/arrival
- メソッド: PATCH
- 認証: ログイン必須

## リクエスト
### パスパラメータ
| 名前 | 型 | 必須 | 説明 |
|------|-----|------|------|
| purchase | 整数 | はい | 更新する発注のID |

### ボディ
| 名前 | 型 | 必須 | 制約 | 説明 |
|------|-----|------|------|------|
| expected_arrival_date | 文字列 | いいえ | YYYY-MM-DD | 入荷予定日 |
| arrival_memo | 文字列 | いいえ | 最大500文字 | メモ |

### 例
POST /purchases/12/arrival
Content-Type: application/x-www-form-urlencoded

_method=PATCH
_token=（CSRFトークン）
expected_arrival_date=2026-06-20
arrival_memo=染工場から連絡あり
//HTMLの<form>ではGETかPOSTしか送信出来ないため、 @method('PATCH')によってLaravelがPATCHとして処理する

## レスポンス
### 成功時
- ステータスコード: **302**（リダイレクト）
- Content-Type: なし（リダイレクト応答のため本文なし）
- 遷移先（Location ヘッダー）: `GET /purchases`（検索中はクエリ付き。例: `/purchases?supplier=東京`）
#### 返るデータの形
| 段階 | ステータス | 形式 | 内容 |
|------|-----------|------|------|
| 1. 保存直後 | 302 | リダイレクト | 発注一覧への移動指示のみ（本文なし） |
| 2. 一覧表示 | 200 | HTML | 発注一覧画面。更新後の日付・メモがフォームに反映されている |
#### セッション（フラッシュメッセージ）
リダイレクトと一緒に、次の1回だけ使えるメッセージがセッションに入る。
| キー | 型 | 例 |
|------|-----|-----|
| success | 文字列 | `発注 PO-2606-002 の入荷予定を更新しました。` |

※ 画面では `resources/views/purchases/index.blade.php` の `session('success')` で表示される。

### エラー時
| コード | いつ | 返る内容 |
|--------|------|----------|
| 302 | バリデーションエラー | 発注一覧へリダイレクト。セッションに errors（例: 「入荷予定日は有効な日付ではありません。」） |
| 404 | 発注IDが存在しない | Laravel 標準の 404 HTML ページ |
| 500 | サーバー障害 | Laravel 標準の 500 HTML ページ |

#### バリデーションエラーの条件（patchArrival の validate より）
| 項目 | ルール | エラーになる例 |
|------|--------|---------------|
| expected_arrival_date | nullable, date | `2026/06/20`（形式不正） |
| arrival_memo | nullable, string, max:500 | 501文字以上 |

## ビジネスルール

### 更新対象
- メモ（`arrival_memo`）は発注種別に関係なく、常に発注テーブルに保存する。
- 入荷予定日（`expected_arrival_date`）の保存先は発注種別によって異なる。
  - 製品・生機発注: 先頭明細の `finish_date` を更新する。
  - 糸発注: 発注の `due_date` を更新する。

### 更新しない条件
- `expected_arrival_date` が空のときは、日付カラムは変更しない（既存値を維持）。
- メモは送られた値で常に上書きする（空文字も可）。

### 画面との関係
- 一覧には日付用フォームとメモ用フォームが別々にある。
- どちらのフォームから保存しても同じ API を呼ぶ。
- 編集していない方の値は hidden 項目で現在値を送り、意図せず消えないようにする。

### 保存後の動き
- 成功時は発注一覧へリダイレクトする。
- 検索中だった場合、検索条件を付けたまま一覧に戻る。

### スコープ外
- 実際の入荷記録・在庫更新は行わない（入荷処理画面の責務）。
